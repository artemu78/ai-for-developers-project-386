# Правила работы с репозиторием

- Используйте Conventional Commits для всех коммитов, включая коммиты агентов.
- Формат: `<type>(<scope>): <description>`; область можно не указывать.
- Основные типы: `feat`, `fix`, `docs`, `test`, `refactor`, `build`, `ci`, `chore`.
- Изменение, несовместимое с предыдущей версией, отмечайте `!` после типа или
  добавляйте строку `BREAKING CHANGE:` в тело коммита.
- Перед коммитом запускайте `npm run check` и `npm run test:e2e`.
